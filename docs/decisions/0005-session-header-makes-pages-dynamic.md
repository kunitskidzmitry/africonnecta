# ADR-0005. Шапка с сессией делает все страницы динамическими

- **Статус:** принято на M1, подлежит пересмотру до публичного запуска
- **Дата:** 2026-09-06
- **Контекст:** §2.2 `docs/implementation-prompt.md`, отступление от требования «SSR + кеш на CDN»

## Контекст

`SiteHeader` показывает «Войти / Создать аккаунт» гостю и «Мой профиль / Выйти» вошедшему.
Чтобы это решить, он читает сессию, а значит — куки. Живёт он в `src/app/[locale]/layout.tsx`,
то есть в дереве каждой страницы.

Чтение куки — динамический API. Next исключает такую страницу из пререндера целиком.
`next build` подтверждает: динамическими стали все маршруты, включая лендинг и полностью
статические `register/check-email` и `register/failed`.

§2.2 требует обратного: задержка Кигали→Франкфурт 150–180 мс, поэтому публичные страницы
обязаны отдаваться из кеша CDN. §2.4 задаёт LCP ≤ 2.5 с на Slow 4G. Сейчас каждый показ
лендинга анонимному посетителю стоит похода на сервер и проверки токена в GoTrue.

## Решение

На M1 оставляем шапку в макете и принимаем динамический рендеринг всех страниц.

## Обоснование

Альтернативы на сегодня хуже:

- **Убрать шапку из макета и собирать её на каждой странице отдельно** — дублирование
  разметки без выигрыша: странице всё равно нужна сессия, чтобы отрисовать нужный вариант.
- **Отрисовывать состояние входа на клиенте** — мигание «Войти» у вошедшего пользователя
  и лишний запрос из браузера, то есть ровно то, что §2.2 запрещает.
- **Включить `cacheComponents` и обернуть шапку в `<Suspense>`** — правильный ответ, но это
  переход на другую модель кеширования во всём приложении (`node_modules/next/dist/docs/
01-app/02-guides/migrating-to-cache-components.md`). Такой переход — отдельная работа
  с отдельной проверкой, а не побочный эффект экрана входа.

Цена сегодня невелика: публичного поиска и публичных профилей ещё нет, лендинг статичен по
содержанию, а трафика нет вовсе. Цена вырастет ровно тогда, когда появится первая страница,
которую индексируют поисковики.

## Последствия

- До публичного запуска необходимо вернуть лендинг и публичные профили в пререндер.
  Ожидаемый способ — `cacheComponents` с `<Suspense>` вокруг шапки.
- Пока это не сделано, `next build` показывает `ƒ` напротив всех маршрутов. Это ожидаемо,
  а не регрессия — но перестанет быть приемлемым, как только появится `/experts/[id]`.
- Бюджет §2.4 (LCP ≤ 2.5 с на Slow 4G) до тех пор не проверяется на живом CDN.
