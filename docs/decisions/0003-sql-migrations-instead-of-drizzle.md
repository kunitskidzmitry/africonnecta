# ADR-0003. SQL-миграции и генерируемые типы вместо Drizzle

- **Статус:** принято
- **Дата:** 2026-09-06
- **Контекст:** WP2 вехи M0. Отступление от §2.2 `docs/implementation-prompt.md`

## Контекст

§2.2 предполагал Drizzle как слой доступа к данным поверх Supabase Postgres.

При реализации выяснилось, что это создаёт **два источника истины о схеме**: SQL-миграции,
которые применяет Supabase CLI, и TypeScript-описание таблиц в Drizzle. Их надо держать
синхронными вручную.

Дополнительно: RLS-политики, триггеры, расширения и `check`-ограничения всё равно пишутся
на SQL. То есть Drizzle покрывал бы только часть схемы, а остальное жило бы в миграциях.

## Решение

- **Источник истины — SQL-миграции** в `supabase/migrations/`.
- Типы генерируются из живой базы командой `npm run db:types`
  (`supabase gen types typescript`) в `src/lib/database.types.ts` и коммитятся.
- Запросы идут через типизированный клиент Supabase. Сложные запросы (двухстадийное
  ранжирование §6.2) реализуются функциями Postgres, а не в коде приложения.
- Drizzle не устанавливается.

## Обоснование

Расхождение двух описаний схемы — типовая ошибка, и заметить её без второго разработчика
трудно (§2.2.1). Генерация типов из самой базы исключает дрейф по построению: тип не может
разойтись со схемой, потому что выведен из неё.

Побочно это убирает целую систему из стека, что прямо соответствует ограничению «один
разработчик без бэкенд-опыта» (§2.2).

## Последствия

- Минус одна зависимость и один слой абстракции.
- Схема пишется на SQL. Это требование к исполнителю, а не недостаток: RLS всё равно на SQL.
- **Известный пробел:** если миграция изменена, а `npm run db:types` не запущен, CI этого не
  заметит — типы закоммичены и типизация пройдёт по устаревшему файлу. Закрывается отдельной
  задачей в CI (поднять базу, перегенерировать, сравнить с закоммиченным). До тех пор —
  дисциплина: **изменил миграцию, запусти `npm run db:types`**.
- Если позже понадобится сложный типобезопасный конструктор запросов, Drizzle можно добавить
  поверх существующих миграций через интроспекцию.
